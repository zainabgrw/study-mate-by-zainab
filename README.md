# 📖 About the Project

StudyMate AI is an AI-powered web application developed to make studying easier, faster, and more interactive.

Instead of switching between different websites for explanations, notes, quizzes, and study planning, students can access everything from a single platform.

The application combines multiple AI-powered educational tools into one modern dashboard to improve learning efficiency.

---

# 🎯 Problem Statement

Students often waste valuable study time searching through multiple websites for explanations, quizzes, notes, and learning resources. This process is time-consuming and can make learning confusing.

StudyMate AI solves this problem by bringing several AI-powered study tools together in one platform. Students can quickly understand concepts, generate quizzes, upload notes, create flashcards, visualize topics with mind maps, and organize their study schedule.

### Target Users

- 🎓 University Students
- 🏫 College Students
- 📘 School Students
- 👨‍💻 Self Learners

# 🤖 AI Feature

The heart of StudyMate AI is its intelligent AI assistant.

The assistant is designed to help students learn instead of simply giving answers.

### AI Capabilities

- Explains difficult concepts
- Answers study questions
- Generates quizzes
- Creates flashcards
- Builds mind maps
- Helps with programming
- Organizes study plans
- Summarizes uploaded notes

### System Prompt

```text
You are StudyMate AI, an intelligent educational assistant.

Your goal is to help students understand concepts rather than simply memorizing answers.

Guidelines:

• Explain concepts using simple language.

• Break difficult topics into easy steps.

• Give accurate educational responses.

• Encourage learning with examples whenever appropriate.

• Generate quizzes and study material when requested.

• Keep responses clear, friendly and concise.

• Focus on helping students improve their understanding.
```

# 🚀 Running the Project

Clone the repository

```bash
git clone https://github.com/zainabgrw/study-mate-by-zainab.git
```

Move into the project

```bash
cd study-mate-by-zainab
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
